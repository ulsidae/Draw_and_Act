# Draw and Act!

<img src="https://github.com/ulsidae/Draw_and_Act/blob/main/thumb.png" height="400" />

A simple multiplayer game originally developed in Korean!

Playtest video: https://www.youtube.com/watch?v=0p6C0voYZ2Q

GitHub Pages: https://ulsidae.github.io/Draw_and_Act/

Draw a picture and record a voice that fits the scene!
Choose a topic and create your own little story with friends or other players by drawing and recording together.

All you need is a device, your imagination, and the ability to describe something with a single continuous line!
Try to get the most votes!

The entire codebase was developed using **vibe coding**.
During the challenge period, I used Codex to develop the multiplayer lobby, real-time P2P connections, drawing sharing, voice recording and playback, scene-by-scene voting and winner selection, and WebM export functionality.

I personally guided and reviewed the development process, including setting the development direction, providing instructions, and reviewing the implementation.
