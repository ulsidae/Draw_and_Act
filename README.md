# Draw and Act!

<img src="https://github.com/ulsidae/Draw_and_Act/blob/main/thumb.png" height="400" />

**Rejected by the hackathon. So I turned it into a web game and added three languages anyway.**

A multiplayer party game where you draw, act, and create your own little story with other players.

**Prototype Playtest:** https://www.youtube.com/watch?v=0p6C0voYZ2Q

**Play:** https://ulsidae.github.io/Draw_and_Act/

## 🎨 How to Play

**1. Choose your language.**

**2. Create or join a story.**

**Host:** Enter the required information, then click **🎨 Create a New Story**.

**Player:** Enter the required information, then click **🚪 Join a Story**.

**3. Share the Room Code.**

The host can share the Room Code with other players. Players using different languages can still play together as long as they enter the correct Room Code.

When you share the room link, the room will open using the host's language settings.

**4. Enjoy! :D**

Draw a picture and record a voice that matches the scene.

Create your own story with friends or other players by drawing and recording together, one scene at a time.

All you need is a device, your imagination, and the ability to describe something with a single continuous line.

**Try to get the most votes!**

## 🛠️ Development

The entire codebase was developed using **vibe coding** with Codex.

I directed and reviewed the development throughout the project, including the overall architecture, feature planning, implementation guidance, and code review.

Codex was used to implement:

* Multiplayer lobby
* Real-time P2P connections
* Drawing synchronization
* Voice recording and playback
* Scene-by-scene voting
* Winner selection
* WebM export

The project runs entirely as a web game and requires no dedicated backend.
